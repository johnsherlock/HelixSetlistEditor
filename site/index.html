Desktop Editor for Line 6 Helix

Build and manage Helix setlists without HX Edit.

Helix Setlist Editor is a focused desktop app for assembling `.hls` setlists, organising `.hlx` presets, and exporting files your Helix can import.

Organise presets fast

Drag presets into place, reorder slots, replace sounds, and alphabetise full setlists when needed.

Work from your folders

Select separate preset and setlist directories, include subdirectories, and keep your existing file structure intact.

Export Helix-ready files

The app rebuilds valid `.hls` containers with the correct zlib wrapper, CRC32, and decompressed byte size.

What it does

  • Open existing `.hls` setlists
  • Create new setlists from a bundled blank template
  • Browse `.hlx` presets from local directories
  • Insert, replace, reorder, remove, and sort presets
  • Save over the original file or export a new copy

Current beta notes

  • macOS ships as a `.dmg` download
