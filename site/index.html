Desktop Editor for Line 6 Helix Setlists

Build and manage Helix setlists without HX Edit

Helix Setlist Editor is a free desktop app for assembling `.hls` setlists files, allowing you to quickly and easily create clean and organised setlists for import into your Helix device.

Download for Mac Download for Windows

Note: Mac builds are currently unsigned beta releases. If Gatekeeper blocks the app or alerts that it is 'damaged' you will need to run the following script to remove it from quarantine. 

sudo xattr -rd com.apple.quarantine /Applications/Helix\ Setlist\ Editor.app

Organise presets fast

Drag presets into place, reorder slots, replace sounds, and alphabetise full setlists when needed.

Work from your folders

Select separate preset and setlist directories, include subdirectories, and keep your existing file structure intact.

Export Helix-ready files

The app rebuilds valid `.hls` containers with the correct zlib wrapper, CRC32, and decompressed byte size.

What it does

  • Open existing `.hls` setlists
  • Create new setlists from a bundled blank template
  • Browse `.hlx` presets from local directories
  • Insert, replace, reorder, remove, and sort presets
  • Save over the original file or export a new copy

Current beta notes

  • Available for macOS and Windows
  • Windows ships as an `.msi` installer
  • macOS ships as a `.dmg` download
  • Desktop app checks for updates on launch
  • Source, release notes, and issue tracking stay on GitHub
