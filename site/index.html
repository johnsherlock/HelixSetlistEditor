MacOS installation steps

The macOS build is currently an unsigned beta that requires a few extra steps to install:

  • Download the macOS beta app, open the `.dmg`, and move Helix Setlist Editor into your `Applications` folder.
  • If macOS warns that the app is from an unidentified developer, right-click the app and choose "Open Anyway" option in Privacy & Security. This can also be permitted under System Settings → Privacy & Security.
  • If macOS says the app is "damaged", remove quarantine in Terminal using the following command: 
    xattr -rd com.apple.quarantine /Applications/Helix\ Setlist\ Editor.app
